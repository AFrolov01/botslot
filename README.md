# Case Bot — Telegram Mini App

Бот `/start` → кнопка **Open App** (+ синяя кнопка Open App в панели ввода) →
мини-приложение с контейнерами и валютами (серебро / золото / хром).

## Структура

```
tg-case-bot/
├── server.js        # Express-сервер + Telegram-бот + API
├── db.js            # SQLite (better-sqlite3), баланс и pending-выигрыш
├── gameLogic.js      # Таблица дропа "Контейнер L"
├── package.json
├── .env.example
├── public/            # Мини-апп (статика)
│   ├── index.html
│   ├── style.css
│   ├── app.js
│   └── assets/         # ваши PNG: silver.png, gold.png, chrome.png, container_l.png
└── data/               # сюда пишется app.db — подключите Railway Volume именно на эту папку
```

## Деплой на Railway

1. Залейте эту папку в свой GitHub-репозиторий (или подключите прямо через Railway CLI).
2. В Railway создайте новый проект → Deploy from repo.
3. **Variables** (вкладка Variables у сервиса):
   - `BOT_TOKEN` — токен бота (уже подставлен как дефолт в коде, но лучше держать в переменной окружения, а не в коде — так безопаснее и его легко сменить без редеплоя).
   - `WEBAPP_URL` — публичный домен, который Railway выдаст вашему сервису (Settings → Networking → Generate Domain). Формат: `https://<ваш-домен>.up.railway.app`. Без `https://` в конце и без слэша.
   - `PORT` — Railway подставляет сам, можно не задавать.
4. **Volume**: Settings → Volumes → Add Volume, точка монтирования `/app/data`. Это обеспечит, что база данных (балансы игроков) не будет стираться при каждом редеплое.
   Переменная `DATA_DIR` по умолчанию уже указывает на `/app/data` — просто оставьте её пустой или явно пропишите `/app/data`.
5. Railway автоматически определит Node.js проект по `package.json` и выполнит `npm install && npm start`.
6. После первого деплоя скопируйте выданный домен в переменную `WEBAPP_URL` и передеплойте (Redeploy) — бот подхватит адрес для кнопок Open App.

## Важно про токен

Токен уже вписан в `server.js` как значение по умолчанию, чтобы бот сразу заработал даже без
настройки переменных окружения. Но для реального продакшена настоятельно рекомендуется:

- задать `BOT_TOKEN` через Variables в Railway,
- убрать хардкод из `server.js` (или хотя бы не публиковать репозиторий публично, раз токен зашит в код).

Если токен когда-либо "утечёт" (например, попадёт в публичный репозиторий) — перевыпустите его
через @BotFather → `/revoke`.

## Что уже реализовано

- `/start` с inline-кнопкой Open App + постоянная синяя кнопка Open App в панели ввода.
- Экран "Валюта": Контейнер L, бесплатно 1 раз в сутки (сброс в 00:00 МСК), иначе 100 серебра.
- Кнопка Кейсы слева с анимированным выездом подменю (Валюта / Музыка / Предметы — последние два пока заглушки).
- Инфо-модалка "i" с таблицей шансов и блоком "Особенное".
- Открытие контейнера → окошки с выпавшими валютами → "Крутить колесо" / "Забрать выигрыш".
- Колесо 50/50: победа удваивает выигрыш, поражение сжигает его.
- Валидация `Telegram.WebApp.initData` на сервере — баланс нельзя подделать, обращаясь к API напрямую.
- Хранение данных в SQLite (файл в `/app/data`, персистентный при подключённом Volume).
